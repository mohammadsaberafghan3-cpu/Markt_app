# NOVA MARKET — multi-vendor marketplace preview

A Persian RTL, mobile-first multi-vendor marketplace rebuilt on an isolated branch. The existing `main` branch and its older deployment are intentionally left unchanged.

## Preview features

- Responsive storefront with product search, category filtering, sample products, and a persistent browser cart
- Customer registration/login and test-mode checkout with stock decrement and order history
- Vendor application and admin approval workflow
- Vendor dashboard: add, edit, hide products; view vendor orders; inspect wallet balance; request settlement
- Admin dashboard: sales and account overview, approve/reject vendors, hide/restore products, move orders through processing/shipped/delivered, manage categories, approve/reject settlement requests, and review audit events
- Commission calculation and internal vendor wallet ledger
- Health endpoint: `/health`

## Important boundaries

- Checkout is **test mode only**. No real payment gateway or bank transaction is connected.
- Settlement approval changes the internal ledger only; it does not transfer money.
- Returns/refunds, carrier integrations, shipping label generation, image upload storage, notifications, product variants, customer support workflows, and complete accounting reports are not implemented.
- The seeded NOVA Select catalog is sample content for preview; it is not a real seller account.
- Render Free uses temporary disk storage. This preview must not be used for real orders or production customer data. For production, move SQLite to a persistent disk or use a managed database, add payment/shipping integrations, and complete security and end-to-end testing.

## Deploy this preview on Render

1. In Render, create a **new Blueprint** from this repository and select branch `nova-market-rebuild` (do not change the existing service connected to `main`).
2. Use the `render.yaml` blueprint in the repository.
3. Set a strong, unique `ADMIN_PASSWORD` when Render prompts for the unsynced secret. `SESSION_SECRET` is generated by Render.
4. Wait for the deploy to finish, then open the generated `.onrender.com` address. Check `/health` for an `ok: true` response.

The admin email defaults to `admin@novamarket.local`; it can be changed with `ADMIN_EMAIL`. The password is never published in this repository and must be supplied as a Render secret.

## Local run

Node.js 20+ and native build tools are required for `better-sqlite3`.

```bash
npm install
ADMIN_PASSWORD='replace-with-a-strong-password' SESSION_SECRET='replace-with-a-long-random-secret' npm start
```

Open `http://localhost:3000`.

GitHub Actions runs JavaScript syntax checks and database smoke tests on this branch and on pull requests to `main`.
